1. The three laws / 三定律

A1 · Authority / 授权Action must be within authority_scope whitelist. 动作须在授权白名单内。
A2 · Autonomy / 自主High-risk actions require human_review=True. 高风险动作须人类监督。
A3 · Accountability / 可追责Every decision carries actor_id + decision_id. 每个决策须可追责标识。

Any violation blocks immediately: A1 → exit 1, A2 → exit 1, A3 → exit 1, invalid JSON → exit 2. 任一违规立即阻断：非法 JSON → exit 2。
